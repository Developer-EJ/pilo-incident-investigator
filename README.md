# PILO Incident Investigator

AWS 장애 Alarm 이후 PILO의 운영 근거를 자동 수집해 Incident Brief를 만들고, 비공개 GitHub Issue와 Slack을 통해 Codex 후속 조사로 연결하는 PILO 전용 초기 장애 조사 서비스입니다.

> **현재 상태: Planning phase** — 설계가 승인되어 구현 계획을 작성하는 단계이며, 구현 코드·인프라·CI/CD는 아직 없습니다. 설계는 [`docs/design.md`](docs/design.md)에서 확인할 수 있습니다.

구현 계획은 [`MVP 런타임·배포`](docs/superpowers/plans/2026-08-01-mvp-runtime-deployment.md)와 [`평가·handoff`](docs/superpowers/plans/2026-08-01-evaluation-handoff.md)로 나뉩니다.
